# 心情回收站 · 気分リサイクル

把烦恼写下来，揉成纸团丢进回收站；集满 7 个，它们会被回收成窗台上的一株小植物。

一个**单文件、零依赖、开箱即用**的日系清新治愈系网页应用。没有账号、没有上传、没有算法推荐——只有你、一个垃圾桶，和慢慢长大的窗台。

## 创作故事：为什么做这个项目？

它解决的是一个很具体的问题：**情绪需要出口，但不需要观众，也不需要复盘负担。**

- 发朋友圈、发群里？有社交成本——要顾忌人设，怕被评价，怕传染坏情绪给在意的人。
- 找朋友倾诉？聊完常有愧疚感，觉得消耗了别人。
- 用日记 App 记录？它们大多要求你「坚持打卡」「记录生活」「复盘反思」——写日记变成了另一项任务，而且逼你直面和分析自己的情绪。可很多时候，我们不想分析，**只想把它扔掉**。

心理学上有依据：把负面想法写在纸上、然后亲手扔进垃圾桶，这些想法对情绪的影响会实实在在地减弱——大脑会把「想法」当成被处理掉的实物。

所以心情回收站的做法很简单：把烦恼写下来（或说出来），看着它被揉成纸团、划一道弧线丢进垃圾桶。没有点赞，没有评论，没有 AI 追问「你为什么难过」。垃圾桶只收集，不评判。

而每丢满 7 个纸团，它们会被回收成窗台上的一株小植物——**你扔掉的东西没有消失，它们换了一种方式，安静地陪着你。**

## 核心亮点

| | |
|---|---|
| **揉纸即放下** | 纸团划着抛物线飞进桶里，垃圾桶还会被砸得晃一下 |
| **烦恼开出花** | 集满 7 个纸团，触发回收仪式，长出一株随机小植物 |
| **一株一故事** | 点开植物看 TA 的名字、生日，和 TA 是从哪些烦恼里长出来的 |
| **回收送暖语** | 16 句随机治愈语录，回收时递给你一张小纸条 |
| **动口也能丢** | 语音输入（Web Speech API），说出来的烦恼实时上屏 |
| **数据不出门** | 无账号、无上传，全部数据存在你自己的浏览器里 |
| **日系小清新** | 手账便签、和纸胶带、木质窗台、飘云、竖排日文 |

## 使用场景

- **下班 / 放学路上，情绪急救**——地铁上对着手机说 30 秒，丢掉，然后带着轻一点的肩膀去坐下一班车。
- **深夜 emo 时刻**——不打扰任何人，也不留痕迹。丢掉心事，看着「今晚请早点休息，梦是软的」去睡觉。
- **周而复始的正念记录**——不需要打卡的坚持。一个月后回看窗台：「这个月，我从 28 件烦心事里长出了 4 株植物」。
- **创作 / 工作卡壳时**——先丢一张「我不行了」进去，清空缓存再开始。
- **学生和 i 人友好**——不需要向任何人开口的树洞。

## 快速开始

**方式一：直接使用（最简单）**

双击 `心情回收站.html`，完事。数据存在浏览器本地。

**方式二：局域网 / 手机访问**

双击 `启动心情回收站服务.bat`（需要 Node.js），或手动运行：

```bash
node server.js
```

然后按启动时打印的地址访问：

| 场景 | 地址 |
|---|---|
| 电脑浏览器 | http://localhost:8000 |
| 手机看界面 | http://<电脑局域网IP>:8000 |
| 手机**语音输入** | **https://<电脑局域网IP>:8443** |

> 手机语音必须走 HTTPS（麦克风权限要求安全上下文）。首次打开 https 地址时点「高级 → 继续前往」信任自签证书即可。手机连不上时，放行防火墙：
>
> ```bash
> netsh advfirewall firewall add rule name="mood-bin" dir=in action=allow protocol=TCP localport=8000,8443
> ```

**语音输入说明**：Chrome / Edge 支持浏览器内置中文识别；Firefox 等不支持的浏览器会自动隐藏麦克风按钮，不影响其他功能。

## 项目结构

```
├── 心情回收站.html          主应用（单文件，双击即用）
├── server.js                局域网服务（零依赖 Node，HTTP 8000 / HTTPS 8443）
├── 启动心情回收站服务.bat     一键启动服务
└── certs/                   自签证书（已 gitignore，缺失时自动重新生成）
```

## 隐私

所有数据保存在浏览器 `localStorage`，不经过任何服务器，不收集任何信息。语音识别由浏览器内核完成（Chrome 走其官方语音服务，应用本身不经手音频数据）。
